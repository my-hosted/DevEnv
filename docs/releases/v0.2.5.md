# DevEnv v0.2.5 Private Preview

DevEnv `v0.2.5`（Build `11`）是面向早期测试者的预览版本，不属于稳定正式版。本版本累计了 `v0.2.4` 以来的全部变更。

## 主要变更（v0.2.4 → v0.2.5）

### 应用内检查更新与下载（#114）
- 从公开的 `my-hosted/DevEnv` GitHub Releases 检查最新预览版；发现新版本后可在应用内下载 DMG 并校验 SHA-256，再打开安装包手动完成更新；不会自动替换已安装的 App。
- 入口：菜单栏「检查更新…」、应用菜单「DevEnv → 检查更新…」，以及「设置 → 更新」区块（含「自动检查更新」开关与「立即检查更新…」）。
- 限制检查频率：自动检查每 24 小时最多一次（持久化上次检查时间，失败也记录），手动检查 30 秒冷却；遇到 GitHub 访问频率限制时提示可重试时间，避免耗尽未登录 API 的每小时 60 次额度。
- 支持「跳过此版本」；下载后校验失败会自动删除文件并提示重试。

### 项目级环境变量注入（#113）
- 可为项目保存一段 Shell 注入片段（例如 `source .env`、`direnv allow`、`nvm use` 或若干 `export`），在该项目关联的每个运行配置执行前、于该次执行的工作目录内先运行。
- 注入不改变配置命令本身，不适用于未关联该项目的运行配置；注入内容随启动冻结进本次运行执行。

### 运行配置平铺视图与拖拽排序（#111）
- 运行配置支持平铺卡片视图。
- 拖拽时显示浮动卡片预览与落点占位，松手落位排序；支持单卡全屏。

### 工作区运行配置拖拽分栏（#110）
- 工作区页运行配置支持拖拽分栏布局，并可关闭详情面板。

### 其它改进
- 项目列表操作菜单改用统一图标按钮。
- 双击窗口顶部或左侧导航空白处可铺满屏幕 / 还原。
- 优化工作区页顶部样式与运行配置交互。

## 升级与数据

从 v0.2.4 升级继续沿用 schema 9（项目级环境变量注入）。升级前建议备份本机 App 数据。运行会话和终端输出只存在于当前 App 进程，升级时不会迁移；请先结束需要保留的工作，完全退出旧版后再替换 App。

## 系统要求与安装

- macOS 15.0 或更高版本，Apple Silicon `arm64`；不包含 Intel 构建。
- Bundle ID：`io.github.zh826256645.DevEnv`。
- 下载 `DevEnv-0.2.5-arm64.dmg` 和对应 `.sha256` 文件，先验证摘要再安装。
- 打开 DMG，将 App 拖入 `Applications`，再启动新版。

## 签名与首次打开限制

App 使用 ad-hoc 签名，仅用于 Bundle 完整性校验；没有 Developer ID 签名、Apple 公证或 Stapling。首次打开如被 Gatekeeper 阻止，请先尝试打开，再通过“系统设置 → 隐私与安全性”确认打开。不要全局关闭 Gatekeeper，也不要递归移除隔离属性。

## 应用内更新说明

- 检查更新使用公开的 `my-hosted/DevEnv` Releases；未登录 API 每小时 60 次额度，因此自动检查限制为每 24 小时一次，手动检查有 30 秒冷却。
- 下载完成后只提供「打开安装包」与「在 Finder 中显示」，不自动替换已安装的 App。自动安装需等 Developer ID 签名与 Apple 公证具备条件后再评估。
- 应用内通过 URLSession 下载通常不会附带隔离属性，但未公证的 App 在其它来源下载时仍可能被 Gatekeeper 拦截并要求手动授权。

## Known Limitations

- 不提供稳定性或长期兼容性承诺，不提供自动替换安装（自动更新）。
- 持续终端支持 zsh、bash、fish 和 sh；停止只发送 Ctrl+C，不强制杀死无响应命令。
- 本地服务仅观察 TCP 监听，不等同于健康检查；DevEnv 不启用 App Sandbox，命令以当前用户权限执行。

## SHA-256 校验

将 `DevEnv-0.2.5-arm64.dmg` 与 `DevEnv-0.2.5-arm64.dmg.sha256` 放在同一目录后执行：

```bash
shasum -a 256 -c DevEnv-0.2.5-arm64.dmg.sha256
```

预期显示 `DevEnv-0.2.5-arm64.dmg: OK`；校验失败时不要安装。
