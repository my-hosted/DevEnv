# DevEnv v0.2.10 Private Preview

DevEnv `v0.2.10`（Build `16`）是面向早期测试者的预览版本，不属于稳定正式版。本版本累计了 `v0.2.9` 以来的全部变更。

## 主要变更（v0.2.9 → v0.2.10）

### 登录恢复 / 后台启动后主窗口不出现、菜单栏唤起无效（#125）
- 修复重启 Mac 并勾选「重新打开窗口」后，菜单栏能看到 DevEnv 图标、但没有任何主窗口，且点「打开 DevEnv」无效的问题。
- 根因是主窗口唤起唯一依赖 SwiftUI 单例 `Window` 场景在 `onAppear` 中注册的回调；在登录恢复 / 后台启动路径下，SwiftUI 不会自动创建该场景窗口，回调始终缺失，于是菜单栏与 Dock 唤起都变成静默空操作，只有完全退出 App 再手动启动才能恢复。
- 现在当 SwiftUI 场景未建窗时，App 会用 AppKit 兜底窗口直接呈现主窗口；SwiftUI 场景窗口一旦出现会自动关闭兜底窗口，避免重复。

### 主窗口恢复到屏幕外时自动校正
- 当状态恢复把主窗口放到已断开的外接显示器（或完全落在所有屏幕之外）时，启动唤起会把窗口移回主屏可见区域居中显示。

## 升级与数据

从 v0.2.9 升级继续沿用 schema 9，不包含数据结构变更。升级前建议备份本机 App 数据。运行会话和终端输出只存在于当前 App 进程，升级时不会迁移；请先结束需要保留的工作，完全退出旧版后再替换 App。

## 系统要求与安装

- macOS 15.0 或更高版本，Apple Silicon `arm64`；不包含 Intel 构建。
- Bundle ID：`io.github.zh826256645.DevEnv`。
- 下载 `DevEnv-0.2.10-arm64.dmg` 和对应 `.sha256` 文件，先验证摘要再安装。
- 打开 DMG，将 App 拖入 `Applications`，再启动新版。

## 签名与首次打开限制

App 使用 ad-hoc 签名，仅用于 Bundle 完整性校验；没有 Developer ID 签名、Apple 公证或 Stapling。首次打开如被 Gatekeeper 阻止，请先尝试打开，再通过“系统设置 → 隐私与安全性”确认打开。不要全局关闭 Gatekeeper，也不要递归移除隔离属性。

## 应用内更新说明

- 检查更新使用公开的 `my-hosted/DevEnv` Releases；未登录 API 每小时 60 次额度，因此自动检查限制为每 24 小时一次，手动检查有 30 秒冷却。
- 只有真正的限流响应会提示可重试时间；其他 HTTP 失败按普通错误显示。
- 下载完成后只提供「打开安装包」与「在 Finder 中显示」，不自动替换已安装的 App。自动安装需等 Developer ID 签名与 Apple 公证具备条件后再评估。
- 应用内通过 URLSession 下载通常不会附带隔离属性，但未公证的 App 在其它来源下载时仍可能被 Gatekeeper 拦截并要求手动授权。

## Known Limitations

- 不提供稳定性或长期兼容性承诺，不提供自动替换安装（自动更新）。
- 持续终端支持 zsh、bash、fish 和 sh；停止只发送 Ctrl+C，不强制杀死无响应命令。
- 本地服务仅观察 TCP 监听，不等同于健康检查；DevEnv 不启用 App Sandbox，命令以当前用户权限执行。

## SHA-256 校验

将 `DevEnv-0.2.10-arm64.dmg` 与 `DevEnv-0.2.10-arm64.dmg.sha256` 放在同一目录后执行：

```bash
shasum -a 256 -c DevEnv-0.2.10-arm64.dmg.sha256
```

预期显示 `DevEnv-0.2.10-arm64.dmg: OK`；校验失败时不要安装。
